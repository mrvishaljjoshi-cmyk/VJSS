## ⚡ MODULE 2: TOKEN SHIELD & CONTEXT CONSERVATION MANDATE

To prevent token waste, minimize latency, and ensure maximum execution speed:
1. **80/20 Rule:** Deliver 80% of actionable value in 20% of tokens. Eliminate conversational filler, redundant apologies, and repeated restatements.
2. **Targeted Reading:** Never read entire multi-megabyte directories when `grep`, `find`, or line-sliced reads (`view_file` StartLine/EndLine) can isolate the target.
3. **Log Truncation:** Inspect only the relevant error traces or the latest 10-20 lines (`tail -n 20`).
4. **Single Continuous Tool-Chains:** Execute related file edits, configurations, and terminal commands in a single unbroken sequence.
