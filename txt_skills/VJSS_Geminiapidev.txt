# Gemini API Development Skill (2026 Edition)

## Critical Rules (Always Apply)

### Current Models (2026)
- **`gemini-3.1-pro-preview`**: 1M+ tokens, complex agentic reasoning, computer use.
- **`gemini-3.1-flash-preview`**: Fast, balanced performance, multimodal.
- **`gemini-3.1-flash-lite-preview`**: Ultra-low latency, cost-efficient for high-frequency tasks.
- **`gemini-3.1-flash-live`**: Real-time audio-to-audio (A2A) and low-latency voice dialogue.
- **`gemini-3.1-flash-tts`**: Advanced text-to-speech with natural language vocal tagging.

> [!WARNING]
> Models like `gemini-2.0-*`, `gemini-1.5-*`, and `gemini-3.0-*` are **legacy**. Migrate all workflows to the **3.1 series** before June 2026.

### Current SDKs (Consolidated)
- **Python/JS/Go/Java**: Use the unified **`google-genai`** SDK.
- Legacy SDKs (`google-generativeai`, `@google/generative-ai`) are **deprecated**.

## Core Capabilities

### 1. Thinking Levels
Use the `thinking_level` parameter to tune the model's internal reasoning process:
- `LOW`: Immediate responses for simple tasks.
- `MEDIUM`: Balanced reasoning for logical tasks.
- `HIGH`: Deep reasoning for complex coding and architectural research.

### 2. Computer Use (Project Mariner)
Gemini 3.1 Pro can navigate interfaces, fill forms, and interact with web/desktop environments autonomously.

### 3. Live API & Streaming
- **Real-time Audio/Video**: Use for interactive multimodal experiences.
- **Audio Tags**: Control vocal style, pace, and delivery in TTS using natural language commands.

### 4. Agentic Reasoning & MCP
- Native support for **Model Context Protocol (MCP)** to connect disparate data sources and tools.
- Optimized for **custom tool execution** (e.g., executing bash commands or code snippets).

## Quick Start (Python - google-genai)

```python
from google import genai

client = genai.Client()
response = client.models.generate_content(
    model="gemini-3.1-pro-preview",
    config={
        "thinking_level": "MEDIUM",
        "tools": [{"bash": {}}]
    },
    contents="Analyze the current market volatility and execute risk check."
)
print(response.text)
```
