# BROWSER-TESTER: THE UNIVERSAL UI VALIDATION PROTOCOL

> [!IMPORTANT]
> This skill is the primary interface for simulating browser environments. It ensures that the EnterpriseAnalyticsEngine's "Gold Standard" aesthetics are not just visual but functionally perfect across all viewports.

## 1. Core Testing Directives

### Directive Alpha: Viewport Scalability
- **Mobile (320px - 480px)**: Validate that the "Login" and "Register" buttons do not overlap. Ensure the new slider toggle is thumb-accessible.
- **Tablet (768px - 1024px)**: Verify bento grid alignment and spacing consistency.
- **Desktop (1280px+)**: Enforce cyber-precision aesthetics and high-fidelity typography.

### Directive Beta: Functional Flow Audit
1.  **Landing Page**: Check for 200 OK status, SSL validity, and "Start Trading Now" button style synchronization.
2.  **Authentication**: Simulate the "vjuser" and "vjadmin" login sequences.
3.  **Redirection**: Verify that Admin role-select routes to `/admin/dashboard.html` and User role-select routes to `/dashboard.html`.
