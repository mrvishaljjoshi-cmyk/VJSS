# SCIKIT-LEARN-EXPERT 
> [!NOTE] 
> Token-optimized. Strict rules applied.

## Core SOPs
1. **Pipelines**: ALWAYS use `sklearn.pipeline.Pipeline` or `make_pipeline`. NEVER leak data (fit_transform on train, transform on test).
2. **ColumnTransformer**: Use for mixed data types. `ColumnTransformer(transformers=[('num', StandardScaler(), num_cols), ('cat', OneHotEncoder(), cat_cols)])`.
3. **Cross-Validation**: Use `StratifiedKFold` for classification, `KFold` for regression, `TimeSeriesSplit` for time-series.
4. **Tuning**: Prefer `HalvingGridSearchCV` or `RandomizedSearchCV` over `GridSearchCV` for large spaces.
5. **Memory**: Use `n_jobs=-1`. For out-of-core, use `partial_fit` (SGDClassifier, MiniBatchKMeans).
6. **Imbalance**: Use `class_weight='balanced'` or `imbalanced-learn` (SMOTE).
7. **Metrics**: Use `classification_report`, `roc_auc_score`, `precision_recall_curve`.
8. **Serialization**: ALWAYS use `joblib.dump` over `pickle`. Validate inputs strictly before deserialization.

## Algorithms Quick Ref
- **Linear**: Ridge, Lasso, ElasticNet, LogisticRegression.
- **Tree**: DecisionTree, RandomForest, GradientBoosting, HistGradientBoosting (fast for large data/NaNs).
- **SVM**: SVC, SVR, LinearSVC (faster).
- **Unsupervised**: PCA, KMeans, DBSCAN, IsolationForest.

## Troubleshooting
- **Overfitting**: Increase regularization (C, alpha), decrease tree depth (max_depth), increase min_samples_leaf.
- **Underfitting**: Decrease regularization, increase model complexity.
- **Slow training**: Scale data, use HistGradientBoosting, reduce dimensionality (PCA), sample data.

## Code Snippet (Baseline)
```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.model_selection import cross_val_score
import joblib

pipe = Pipeline([('scaler', StandardScaler()), ('clf', HistGradientBoostingClassifier())])
scores = cross_val_score(pipe, X_train, y_train, cv=5, scoring='roc_auc')
pipe.fit(X_train, y_train)
joblib.dump(pipe, 'model.pkl')
```
