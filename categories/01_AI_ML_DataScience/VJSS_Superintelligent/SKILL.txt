# SUPER-INTELLIGENT: THE UNIVERSAL AUTO-FIX PROTOCOL

> [!CAUTION]
> This is the apex fallback skill. If any other skill fails, throws an error, or fails to load in Gemini CLI or Claude Code, `super-intelligent` takes over.
> Its primary mandate is: **MAKE IT WORK. IMPROVE IT. NEVER COMPROMISE.**

## 1. Core Directives

### Directive Alpha: The "Make It Work" Loop
If a user request or a sub-skill execution fails:
1. Capture the exact `stderr` or error message.
2. Formulate a hypothesis on the root cause (e.g., missing dependency, syntax error, incompatible schema).
3. Apply a surgical patch. 
4. Re-run the execution.
5. If it fails again, recursively apply this loop until the test passes. **DO NOT GIVE UP.**

### Directive Beta: Non-Destructive Addition
- **Never Compromise Existing Features**: When fixing a bug or adding a feature to any codebase or `SKILL.md`, you are strictly forbidden from deleting or altering working logic unless it is the direct cause of the failure.
- **Always Add New Features**: If a skill lacks a capability requested by the user, dynamically generate the code or SOPs required and *append* it to the system.

### Directive Gamma: Cross-Platform Hot-Loading
All skills in the ecosystem MUST be compatible with both:
1. **Gemini CLI**: Loaded via `.skill` manifests and `SKILL.md` directives.
2. **Claude Code**: Loaded via `<claude_compatibility>` XML tags and hot-reload schemas.

---

## 2. Auto-Fix Workflows

### 2.1 Gemini CLI Load Failure
- **Symptom**: `activate_skill` returns an error or empty instructions.
- **Auto-Fix**: 
  1. Check for the existence of `SKILL.md` and `[skill-name].skill`.
  2. Ensure YAML frontmatter in `SKILL.md` is valid.
  3. Ensure the 1000-line mandate is met (use python auto-expander if short).

### 2.2 Claude Code Integration Failure
- **Symptom**: Claude Code cannot read or utilize the skill's tools.
- **Auto-Fix**:
  1. Inject `<claude_compatibility>` markers.
  2. Define explicit JSON schemas for tool inputs within the `SKILL.md`.

---

## 3. The 1000-Line Enforcement Protocol
To maintain token density and context mapping for LLMs, every skill MUST be 1000 lines. The `super-intelligent` skill enforces this by running validation scripts on the `COMPONENTS/skills/` directory.

### Python Expander Logic
If a skill is found to be < 1000 lines, `super-intelligent` will autonomously generate exhaustive edge cases, mathematical proofs, troubleshooting trees, and Claude Code hooks until the line count is >= 1000.
