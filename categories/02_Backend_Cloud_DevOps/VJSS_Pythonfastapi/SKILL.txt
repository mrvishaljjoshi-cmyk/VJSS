## 1. 🎯 PLAIN-ENGLISH OVERVIEW & LAYMAN INTRODUCTION

### What is this?
FastAPI is a modern, high-speed Python web framework for building REST APIs with automatic data validation (Pydantic v2), asynchronous request handling (asyncio), and auto-generated interactive OpenAPI/Swagger documentation.

### Why does it matter?
Without this protocol, implementations are prone to logic errors, security vulnerabilities, unhandled edge cases, and performance bottlenecks. This skill establishes an exact, deterministic playbook.

### When to use it?
- Whenever you need to build, refactor, debug, or optimize systems involving **Pythonfastapi**.
- When collaborating with AI agents to guarantee zero hallucinations and production-grade code.

Follow these exact steps sequentially:

2. **Step 2:** Enforce Pydantic v2 BaseModel schemas with strict typing, Field constraints, and ConfigDict(from_attributes=True).

## 4. ⚡ PRODUCTION-GRADE CODE ARCHITECTURE & SNIPPETS

```python
from fastapi import FastAPI, Depends, HTTPException, status
from fastapi.middleware.cors import CORSMiddleware
from pydantic import BaseModel, Field, ConfigDict
from contextlib import asynccontextmanager
from typing import AsyncGenerator
import httpx

class ItemCreate(BaseModel):
    name: str = Field(..., min_length=2, max_length=100, description="Item identifier name")
    price: float = Field(..., gt=0.0, description="Unit price in base currency")
    is_active: bool = Field(default=True)
    model_config = ConfigDict(from_attributes=True)

class ItemResponse(ItemCreate):
    id: int

@asynccontextmanager
async def lifespan(app: FastAPI):
    # Startup: Initialize async DB connection pools & HTTP clients
    app.state.http_client = httpx.AsyncClient(timeout=10.0)
    yield
    # Shutdown: Cleanly close pools
    await app.state.http_client.aclose()

app = FastAPI(title="Enterprise API", version="2.0.0", lifespan=lifespan)

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://vjprojects.co.in"],
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE"],
    allow_headers=["*"],
)

@app.post("/api/v1/items", response_model=ItemResponse, status_code=status.HTTP_201_CREATED)
async def create_item(payload: ItemCreate):
    # Business logic execution
    return ItemResponse(id=101, **payload.model_dump())
```

## 5. 🛡️ SECURITY, VALIDATION & FOOL-PROOF HARDENING

• **Security Rule:** Never use allow_origins=['*'] in production with allow_credentials=True.
• **Security Rule:** Always sanitize and validate path/query parameters with Pydantic Field regex or validators.
• **Security Rule:** Use passlib with bcrypt or argon2 for password hashing, and python-jose for RS256 JWT tokens.
• **Security Rule:** Implement rate limiting using slowapi or Redis token-bucket algorithms.

---

## 6. ⚠️ COMMON PITFALLS & EDGE CASES

• **Trap:** Blocking the event loop: using time.sleep() or sync requests inside async def routes (use asyncio.sleep and httpx).
• **Trap:** N+1 database queries: missing selectinload / joinedload in async SQLAlchemy relationships.
• **Trap:** Memory leaks from unclosed HTTP client sessions: always bind client lifecycle to lifespan.
